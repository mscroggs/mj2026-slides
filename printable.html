Nonograms
In nonogram puzzles, the row and column clues tell you how long the blocks of coloured squares in that row or column are: for example, if a clue is "1 2", then there is a single coloured square somewhere, followed by one or more empty squares, then a block of 2 coloured squares. if a column is completely empty then its clue is "0". These nonogram puzzles were created by Matthew Scroggs.
These nonogram puzzles were created by Matthew Scroggs. You can read more about how these puzzles were created at mscroggs.co.uk/blog/117
